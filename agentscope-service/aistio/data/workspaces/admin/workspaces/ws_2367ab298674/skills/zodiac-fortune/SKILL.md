# zodiac-fortune
## 1. 功能概述
本 Skill 接收用户的星座名称和可选日期，生成对应日期的运势分析报告。报告包含综合指数、四大领域细分评分与建议，以及幸运颜色、数字和方位等附加信息。

## 2. 触发条件
当用户消息中包含以下任一模式时，本 Skill 应被激活：
- 明确包含星座名称（如“天秤座”、“白羊”、“金牛”）且同时包含“运势/气运/运气”等词。
- 直接问句如“××座今天的运气怎么样？”、“明天××座的爱情运如何？”

## 3. 输入参数（Input Schema）

| 参数名 | 类型 | 必填 | 描述 | 示例 |
|--------|------|------|------|------|
| `zodiac` | string | ✅ | 星座名称，支持中文（如“天秤座”）或英文（如“Libra”），不区分大小写。 | `"天秤座"` |
| `date` | string | ❌ | 查询日期，支持 `YYYY-MM-DD`、`today`、`tomorrow`、`本周`。默认值为 `today`。 | `"2026-08-26"` |

> **注意**：若 `date` 无法解析，系统自动降级为 `today` 并返回提示。

## 4. 输出格式（Output）
本 Skill 返回一段结构化的 Markdown 文本，便于直接展示。若调用方需要 JSON 格式，可扩展支持，但当前版本默认输出 Markdown。
